# Origen y licencia de las imágenes (Fase 1)

Todas las fotografías se procesaron con una gradación de color unificada (desaturación cálida) para coherencia de campaña.
Archivos en `src/assets/images/`. Para reemplazarlas, sustituye el archivo manteniendo el nombre, o actualiza
`src/config/media.ts`, `src/data/demo/products.ts` y `src/data/demo/collections.ts`.

> Estas imágenes son **provisionales**. Antes del lanzamiento deben sustituirse por la fotografía oficial de INVESTMENTS
> (recomendado: mínimo 2400 px en el lado largo para el hero).
